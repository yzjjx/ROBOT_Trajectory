首先是两个直线轨迹

## 2 直线轨迹
### 2.1 直线轨迹2
直线轨迹2为400mm水平直线，在进入轨迹与出去轨迹的时候，需要一定的余量，将余量设置为50mm，一共为500mm的直线，首先要定义机器人的工具中心点  
首先采用的方案是RoboDK的机器人轨迹规划，在RoboDK中先规划机器人的轨迹，如图3所示，然后利用Python程序导出机器人1000Hz的关节点位q，然后将其输入到机器人里面
